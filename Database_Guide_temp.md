# Инструкция по работе с Базой Данных KoFFPanel

Эта инструкция поможет тебе понять, как устроено "сердце" программы — её база данных.

## 1. Что это такое?
Программа использует базу данных **SQLite**. Это один файл (`koffpanel_users.db`), в котором хранятся все настройки, пользователи и их история. Чтобы данные были в безопасности, файл зашифрован с помощью **SQLCipher**.

## 2. Где лежат ключи?
Для защиты используется файл `koffpanel_db.key`. Он содержит зашифрованный пароль от базы данных. Пароль привязан к твоему пользователю Windows, поэтому просто так скопировать базу на другой компьютер и открыть не получится.

## 3. Из каких "ящиков" (таблиц) состоит база?

### Таблица `Clients` (Пользователи)
Это самая важная таблица. В ней хранятся:
- **Email**: Почта пользователя (его логин).
- **Uuid**: Уникальный секретный ключ для подключения.
- **TrafficLimit**: Сколько гигабайт интернета можно потратить.
- **TrafficUsed**: Сколько уже потрачено.
- **IsActive**: Включен пользователь или заблокирован.
- **ExpiryDate**: До какого числа работает подписка.

### Таблица `TrafficLogs` (История трафика)
Тут программа записывает, сколько мегабайт каждый пользователь тратит каждый день. Это нужно для красивых графиков.

### Таблица `ConnectionLogs` (История подключений)
Здесь хранится информация о том, с каких IP-адресов и из каких стран заходил пользователь.

### Таблица `ViolationLogs` (Нарушения)
Если пользователь пытается качать торренты или подключается с 10 устройств сразу, Антифрод записывает это сюда.

## 4. Как программа работает с базой? (Для "прогеров")

1. **AppDbContext.cs**: Это главный класс-посредник. Когда программе нужно что-то из базы, она обращается к нему.
2. **Entities**: Это "шаблоны" данных (классы C#), которые в точности повторяют структуру таблиц.
3. **Encryption**: При каждом запуске программа читает `koffpanel_db.key`, расшифровывает его через систему Windows (DPAPI) и вводит пароль в базу, чтобы получить доступ.

## 5. Как всё работает вместе (на пальцах)
1. Ты нажимаешь "Добавить пользователя" в программе.
2. Программа создает объект `VpnClient`.
3. `AppDbContext` берет этот объект и превращает его в строчку в таблице `Clients`.
4. Когда пользователь подключается к серверу, программа раз в минуту спрашивает сервер: "Сколько он потратил?".
5. Программа прибавляет это число к `TrafficUsed` в базе и записывает в `TrafficLogs`.
6. Если лимит превышен, программа меняет `IsActive` на `false` и отправляет команду на сервер — "Отключить!".
